## 프로젝트 개요 및 성능 비교

PZ_Optimization은 Build 42용 Java 클래스 오버라이드 패키지입니다. 클래스 파일을 게임 실행 경로에 추가해 청크 스트리밍, 렌더링, 날씨, 로딩 과정의 지연을 줄이도록 설계됐습니다. `projectzomboid.jar` 자체는 수정하지 않으며, 게임의 실제 revision과 맞지 않으면 오버라이드가 비활성화됩니다. 기본 설정은 제작자가 측정한 기준 구성입니다.

원문에서 제공하는 비교 영상은 동일 PC·세이브·동선에서 기본 게임과 최적화 적용본을 비교합니다. 장면마다 병목이 다르므로 FPS 숫자 하나가 모든 상황을 대표하지 않습니다. 특히 120km/h 주행, 로즈우드 시점 회전, 루이빌 좀비 밀집, 짙은 안개 및 번개, 게임 실행과 월드 로딩을 구분해 해석해야 합니다. Windows, macOS, 구형 노트북과 휴대용 기기 측정도 각기 조건이 다릅니다. 다른 Workshop 성능 모드와의 비교 역시 제작자의 특정 장면에 대한 결과로 설명돼 있습니다.

## 설치 및 확인

지원 게임은 Steam의 Project Zomboid **42.20.4** 베타, JAR revision `b0bbce05d5`입니다. Windows, Linux, macOS용 절차가 제시돼 있습니다. Workshop 구독은 파일을 내려받는 단계이며, **모드 목록에서 활성화하는 것만으로 Java 클래스가 설치되지는 않습니다.** 원본 릴리스 또는 Workshop에서 제공하는 설치 스크립트를 게임 종료 후 실행해야 합니다. 오프라인 ZIP 수동 해제 및 Linux 소스 빌드 경로도 원문에 구분돼 있습니다.

설치기는 Steam 라이브러리와 revision을 검사하고, 오버라이드 파일과 목록 파일 `pzopt-installed.txt`를 관리합니다. 정상 실행 시 `Zomboid/console.txt`에서 `[pzopt] loaded override ... active` 로그와 설정 화면의 최적화 탭을 확인할 수 있습니다. 게임 업데이트로 revision이 바뀌면 호환 릴리스를 기다려야 합니다.

제거는 원본의 `install.ps1 -Uninstall` 또는 플랫폼별 제거 절차로 진행합니다. `Zomboid/pzopt/`에 남은 캐시·개인 설정은 별도로 취급합니다. 원본의 자동 업데이트는 게임 내 업데이트 항목에서 실행하며, **한국어 패치가 게임 폴더의 Lua 파일을 교체한 상태라면 먼저 한국어 패치를 복원해야 합니다.**

## 설정, 프레임 제한 및 업스케일링

`설정 → 최적화`에서 전체 기능을 끄거나 개별 키를 조정할 수 있습니다. 값의 우선순위는 설치 디렉터리의 `pzopt.properties` 및 JVM `-Dpzopt.<key>`가 사용자 옵션 탭보다 높습니다. 사용자 선택은 `Zomboid/pzopt/options.ini`에 저장되며, 변경된 기능은 다음 실행부터 적용되는 것이 기본입니다. 일부 키가 고정된 환경에서는 컨트롤이 비활성화돼 표시됩니다.

저사양 프로필은 제작자의 4코어 구형 GPU 환경에서 측정한 설정입니다. 이번 릴리스에서는 **텍스처 압축을 함께 활성화**하고, G1 GC가 `gcMode`의 기본값으로 제공되는 변경이 적용됐습니다. 프리셋을 누르면 현재 사용자의 설정이 변할 수 있으므로 변경 전 옵션을 백업하세요. 업스케일링은 AMD FSR 1.0과 NVIDIA DLSS의 지원 조건이 다르며, DLSS는 별도 네이티브 구성 요소가 필요할 수 있습니다. 프레임 제한에는 원본 상한보다 높은 선택값과 메뉴 별도 제한이 있습니다.

F9 성능 오버레이는 프레임 시간, p99/p99.9, GPU·스레드 부하 등 여러 요소를 선택적으로 보여 줍니다. 프레임별 기록과 상세 샘플링은 측정 자체의 비용이 있으므로 필요할 때만 켭니다. 원문은 Steam의 새로운 인게임 성능 모니터가 GL 호출을 직렬화해 측정 결과를 왜곡할 수 있다고 안내합니다.

## 최적화 구현

청크 스트리밍 항목은 월드 청크 준비·후처리와 큐 대기를 다룹니다. 렌더링 항목은 정적 나무, 청크 텍스처, 가림/컷어웨이, 스프라이트 버퍼 등 서로 다른 단계를 대상으로 합니다. 날씨 항목에는 웅덩이, 비, 번개 및 안개 패스가 포함됩니다. 게임 실행과 월드 로딩 최적화는 스레드 사용, 캐시, 파일 처리·디코딩을 분리합니다. 원문에는 측정해 봤지만 채택하지 않은 최적화도 별도로 기록돼 있습니다.

원본의 클래스 오버라이드는 실행 경로에서 게임 JAR보다 앞선 경로에 놓이는 `.class` 파일을 이용합니다. JAR 원본은 수정하지 않는 대신, 동일 클래스를 교체하는 다른 Java 모드와는 충돌할 수 있습니다. 한국어 패치는 해당 실행 로직을 다시 구현하지 않으며 최신 원본의 기능 변경을 그대로 보존해야 합니다.

## 제한사항 및 로드맵

원본의 멀티플레이 검증은 싱글플레이보다 제한적이며, **데디케이트 서버에 클래스 오버라이드를 설치하지 않도록** 안내합니다. `fogPass`는 실험적 기능으로, 환경에 따라 짙은 안개에서 시각적 이상이 발생할 수 있습니다. 지붕 표시와 저사양 4코어 환경의 GC·스레드 경합도 별도 제한사항에 포함돼 있습니다. 플랫폼별 테스트 범위와 아직 끝나지 않은 장시간 플레이 검증은 원본의 Known limitations를 확인하세요.

원문 끝부분에는 향후 개발 계획, 자동 벤치마크 도구 및 저장소 구조가 정리돼 있습니다. 이를 확인할 때는 릴리스와 `master`의 문서 변경을 구분하고, 실제 배포 클래스와 Lua 소스를 우선 검토해야 합니다.
